About

I'm Gauri, a final-year computer science student at VIT Bhopal. I work where images, language and systems meet.

That has meant tracking every player in a football match from broadcast video, building retrieval systems that refuse to answer without a source, and sending disaster warnings over SMS in the languages people actually speak.

I learn best by building things from the bottom up, so I've written a path tracer and a 2D game engine in C++ without borrowing an engine for either. The image at the top of this page is a small version of that path tracer, running live in your browser.
